# Happ VLESS subscription

Автоматически обновляемая подписка VLESS Reality для Happ. Генератор напрямую
использует несколько независимых публичных источников, проверяет соединение через
Xray и публикует небольшой разнообразный набор серверов.

## Как обновляется список

Workflow запускается каждые 2 часа и:

1. Загружает конфигурации напрямую из ConnLiberty, `vpn-free-russia` и
   `ProxyCollector`. Отказ одного источника не останавливает остальные.
2. Оставляет VLESS Reality с транспортом TCP/RAW и удаляет точные дубликаты.
3. Делает быстрый TCP-предфильтр.
4. Для 100 наиболее отзывчивых кандидатов запускает Xray и запрашивает тестовую
   HTTPS-страницу через настоящий SOCKS-туннель. Открытого порта недостаточно.
5. Исключает российские и неопределённые выходные IP и выбирает до 20 узлов с разными адресами,
   `/24`-подсетями, UUID, ASN и странами. Если строгого разнообразия недостаточно,
   ограничения по странам и ASN ослабляются, но адреса, подсети и UUID не повторяются.
   При наличии хотя бы 10 качественных узлов список обновляется, не дожидаясь ровно 20.
6. Сортирует исходный список по расстоянию от Москвы и указывает его в имени узла.
   Happ дополнительно запускает автопинг и сортирует список по задержке, измеренной
   уже с устройства пользователя — это окончательный и более точный порядок.

Публичные бесплатные серверы не дают достоверной статистики одновременных
пользователей. Генератор снижает вероятность перегруженного общего пула с помощью
реальной проверки, сетевого разнообразия и предпочтения адресов, встречающихся в
меньшем числе источников.

## Настройка

Список источников можно заменить через многострочную переменную `VLESS_SOURCES`:

```text
source-name=https://example.com/subscription
backup=https://example.net/vless.txt
```

Основные переменные:

- `VLESS_LIMIT` — число опубликованных узлов, по умолчанию `20`;
- `VLESS_MIN_SERVERS` — безопасный минимум для обновления, по умолчанию `10`;
- `REALITY_TEST_LIMIT` — сколько кандидатов проверять через Xray, по умолчанию `100`;
- `REALITY_TEST_WORKERS` — число параллельных проверок, по умолчанию `4`;
- `REALITY_TEST_TIMEOUT` — тайм-аут одной проверки, по умолчанию `8` секунд;
- `MAX_REALITY_LATENCY_MS` — максимальное время реального HTTPS-теста, по умолчанию
  `3500` мс;
- `XRAY_BIN` — путь к исполняемому файлу Xray.

Ручной запуск обновления: Actions → Update VLESS subscription → Run workflow.

## Маршрутизация в Happ

Подписка импортирует один профиль `Dmitry RU Direct` и при следующих обновлениях
перезаписывает его, а не создаёт новый профиль. Российский трафик определяется в
два этапа: по доменам (`.ru`, `.рф`, `russia-inside`, `category-ru`) и по IP
(`direct`, `russia-inside`). Остальной трафик идёт через VPN. Для Telegram также
заданы доменные правила и его IPv4/IPv6-подсети, чтобы приложение не отправляло
IP-подключения Telegram напрямую.
Gemini и связанные домены авторизации/API Google всегда направляются через VPN.

В Happ маршрутизация изолирована для каждой подписки. После импорта или изменения
профиля нужно открыть «Маршрутизация» у подписки `Fast VPN`, включить общий
переключатель и переподключить VPN. Переключение между серверами внутри `Fast VPN`
должно сохранять этот режим; при переходе на сервер из другой подписки используется
её отдельная настройка маршрутизации.
